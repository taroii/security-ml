# Learnable Obfuscation for Temporally Related Video Data

Code for the paper. The mechanism obfuscates video frame embeddings through
class-`k` mixing, row permutation, random projection, and additive Gaussian
noise; the experiments sweep the obfuscation knobs `(k, sigma)`, measure how
much a membership-inference adversary can recover from the released data, and
measure the accuracy of a downstream action-recognition classifier trained on
it.

This repository contains code only. Every CSV, figure, and table in the paper
is regenerated by running the scripts below; outputs are written to `results/`,
`results_revision/`, `accuracy_results/`, and `images/`.

## Getting started

```
conda create -n security python=3.11.14
conda activate security
pip install -r requirements.txt
```

`requirements.txt` pins the exact versions used for the reported runs. On a
CUDA machine, install `torch` and `torchvision` from
https://pytorch.org/get-started/locally/ first, then install the rest; the
reported runs used the PyTorch MPS backend on Apple silicon and no CUDA GPU is
required.

UCF-101 is downloaded automatically on first use (about 6.5 GB) into `data/`.
Extracting the videos needs `unrar` or `7z` on the PATH.

## How to run

The full sweep runs from one script:

```
bash run_temporal_mia.sh
```

Individual phases:

```
bash run_temporal_mia.sh smoke      # 1-cell, 2-trial sanity check
bash run_temporal_mia.sh mia        # membership-inference sweep over (k, sigma)
bash run_temporal_mia.sh accuracy   # downstream accuracy sweep
bash run_temporal_mia.sh plots      # aggregate CSVs and rebuild tables/figures
```

Override the defaults with environment variables, e.g.

```
N_TARGETS=50 N_TRIALS=10 bash run_temporal_mia.sh mia
K_VALUES="0 1" SIGMAS="0.01 0.10" bash run_temporal_mia.sh
```

`N_TARGETS` (10), `N_TRIALS` (5), `N_CLIP_CANDIDATES` (50),
`N_FRAME_CANDIDATES_A3` (2000), `K_VALUES` (`"0 1 5"`), `SIGMAS`
(`"0.01 0.05 0.10 0.50"`), `ACC_PARALLEL` (1), `SKIP_ACCURACY`, `CONDA_ENV`
(`security`).

### Individual scripts

| Script | What it does |
| --- | --- |
| `src/membership_inference.py` | The mechanism and the three attacks. Run per `k`, sweeping `--sigmas`. |
| `src/main_video.py` | Extracts embeddings, applies the mechanism, trains the Transformer classifier. Run per `(k, sigma)` cell. |
| `src/theory_numerics.py` | Closed-form prior and calibration numerics. `--mode {calibration,prior-figure,frame-survival}`. |
| `src/mi_bound_evaluation.py` | Log-determinant functional on real embeddings. `--replot-only` redraws from the saved CSV. |
| `src/lira_roc.py` | LiRA ROC and TPR at low FPR. `lira_roc.py [run\|plot\|verify]`. |
| `src/correlation_aware_attack.py` | Blind vs. correlation-aware adversary. |
| `src/synthetic_correlation.py` | Controlled AR(1) correlation study. |
| `src/embedding_autocorrelation.py` | Measures ρ(τ) on real frame embeddings. |
| `src/visual_obfuscation.py` | Pixel-space visualization of the mechanism. |
| `src/aggregate.py` | Collates per-cell CSVs. `--mode {attacks,accuracy,pareto}`. |

`theory_numerics.py` and `synthetic_correlation.py` need no dataset.
`membership_inference.py`, `main_video.py`, `correlation_aware_attack.py`,
`embedding_autocorrelation.py`, and `visual_obfuscation.py` require UCF-101.
`mi_bound_evaluation.py`, `lira_roc.py`, and `aggregate.py` read artifacts the
others produce.

Multi-seed accuracy runs use `--seed`, which reseeds every stochastic component
and tags the output filename so seeds do not overwrite one another:

```
for s in 42 43 44; do
  python src/main_video.py --k 1 --sigma 0.10 --seed $s
done
python src/aggregate.py --mode accuracy
```
